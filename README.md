# Ubuntu-desktops-custom

Architecture technique du projet Ubuntu 26.04 LTS Workstation.

## Statut

**SQUELETTE / PRE-TEST ONLY** — aucune exécution réelle sur la workstation n'est autorisée tant que le jalon `PRE-TEST READY` n'est pas validé.

## Domaines

- HOST : Ubuntu Desktop, matériel, applications, gaming.
- KVM : QEMU/libvirt, réseaux, pools, catalogue OS/ISO.
- VM_DEVOPS : Ubuntu Server 26.04, Docker, Kubernetes, Terraform, Ansible, AWS/Azure CLI, DevSecOps.
- BACKUP : sauvegarde, restauration et disaster recovery.
